01 / 老野记事使用指南

记下今天，整理常用。

Mac · iPhone · iPad

  1. 写一条记事。打开应用，在今日卡片中填写标题与正文；可以创建和切换多张卡片。内容随编辑保存到本机。
  2. 整理常用信息。将经常查看的内容放在常用卡片中；通过历史入口查看已归档的日记事。添加附件时，文件会按应用流程复制到本地附件目录。
  3. 了解同步，再连接。让兼容版本的 Mac 与 iPhone / iPad 处于可信的同一网络，按系统提示允许本地网络权限，并在两端打开应用。应用会自动发现兼容设备、建立连接并同步；请先核对界面中的连接状态。
  4. 保留重要资料。同步不是备份。清理卡片、历史或附件前，先另行保存需要保留的内容。
请先了解同步边界。当前没有同一所有者验证或配对码，不保证只连接本人设备。不建议在公共或不可信网络中打开含敏感记事的应用。详见设备发现与连接说明。

02 / 老野网测使用指南

先看状态，再做测量。

Mac · iPhone · iPad

  1. 查看网络状态。打开应用后查看当前连接与互联网状态。运行期间会进行自动网络检查，启动或刷新节点也可能产生请求。
  2. 进行外网测速。在测速页面选择节点；移动端可选择测速档位，再开始测试。查看下载、上传、延迟、抖动与丢包估算。测试会消耗网络流量，蜂窝网络下尤其需要留意。
  3. 排查连通性。在诊断页面检查各目标的响应；单个目标失败不一定代表网络整体不可用，也可能与目标限制、代理或线路有关。
  4. 查看历史。在历史页面比较本机记录；需要时使用清空历史功能。清空本机历史不影响第三方日志。

Mac 还提供内网存储测速、局域网服务发现及泄露检查；iPhone / iPad 不提供相同的任意目录读写测速。内网存储测速只选择你有权访问的目录，网络诊断结果不应被理解为安全认证。

相关请求和第三方处理边界见老野网测隐私政策。

03 / 常见问题

记事没有同步，先检查什么？

先确认两端应用已打开、版本协议兼容、本地网络权限已允许，并处于可信的同一网络。访客 Wi-Fi、设备隔离、防火墙或代理设置可能影响发现。先查看连接状态与错误提示；不要为排查而直接关闭系统防护、重置网络或删除数据。

仍不能同步时，请保留本地资料，并通过技术支持邮箱提供系统与应用版本、错误提示及脱敏的复现步骤。

删除卡片后，其他地方的内容也会消失吗？

不能据此保证。历史、附件引用、其他设备副本、冲突副本和系统备份可能分别保留。删除操作还可能向已连接设备同步删除标记。清理前先备份，逐项确认需要删除的范围。

速度偏低或某个节点无法访问，意味着什么？

测速受 Wi-Fi 信号、运营商线路、代理、目标服务器、同时使用网络的程序和测试档位影响。先停止重复测试，检查应用提示，换一个时段或明确选择的测试目标进行比较；不要把一次结果当作长期结论。

选了不同节点，为什么上下行结果仍可能接近？

当前实现向所选目标做延迟探测，但上下行吞吐测试使用 Cloudflare 接口。节点延迟与吞吐服务并不一定来自同一目标；请分别理解这两类指标。

隐藏 IP 后，第三方还会看到我的 IP 吗？

会看到请求的出口连接信息，可能是你的网络出口或代理出口。隐藏设置控制界面显示，不能隐藏网络请求本身。详情见IP 与连接信息说明。

Mac 的内网测速找不到设备怎么办？

Bonjour 只能发现广播了支持服务的设备；未发现不代表设备不在线。存储测速针对你已挂载或手动选择的目录，不自动替你连接、登录 NAS。请先用系统文件管理器确认访问权限。

怎样下载 App，或向开发者反馈？

两款App即将上线，当前暂无正式下载链接。技术支持可联系 ah5000@live.cn。
