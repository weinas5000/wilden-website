老野网测隐私政策

01 / 适用范围

本说明适用于老野网测的 Mac、iPhone 和 iPad 版本，涵盖网络状态检查、测速、IP 信息、诊断与本地历史。内网存储测速、代理节点识别和泄露检查等功能主要属于 Mac 版本；移动端功能并不完全相同。

本页区分“开发者接收数据”和“网络功能向第三方发送请求”。网络测速并非完全离线：即使应用界面隐藏 IP，目标服务器仍会看到连接出口信息。

02 / 测速与自动网络检查

外网测速向所选节点发出请求以估算延迟；下载与上传吞吐测试使用 Cloudflare 的测速接口。上传测试发送程序生成的固定测试字节，不是读取你的文档后上传。所选节点的延迟与吞吐测试可能涉及不同目标，结果不应理解为每个节点都提供同一套上下行服务。

应用运行时的网络状态监测会进行互联网可达性检查，启动或刷新节点列表也会发起节点探测。这些请求不全部依赖你点击“开始测速”。默认检查目标包括 Apple、Cloudflare、电信、联通及 Google 的连接检查服务；实际请求受可达性和功能触发条件影响。

网络功能会消耗流量。请留意蜂窝网络资费、测试档位及重复测速的流量消耗；不同档位和网络失败重试会改变实际用量。

03 / IP 与连接信息

应用可按功能需要读取或显示本地 IP、IPv6、DNS、网关、网络接口和代理状态，并通过 Cloudflare 查询公网出口 IP、国家或地区及接入点信息。默认界面隐藏部分网络标识，但 Mac 的内网功能仍会读取本地网络信息；隐藏显示不等于不处理，也不能阻止第三方看到请求源 IP。

Mac 泄露检查在触发后使用 ipify、icanhazip 查询 IPv4 / IPv6 出口，读取系统 DNS / 代理信息，并通过 WebRTC 与 Cloudflare、Google、哔哩哔哩 STUN 服务进行临时连接探测。该实现不调用摄像头或麦克风采集 API。泄露检查结果保留在内存中，未见写入测速历史的路径。

接收请求的服务可能看到出口 IP（使用代理时可能是代理出口）、请求时间、目标路径、协议及请求头等网络元数据。测速请求还带有应用 User-Agent。DNS 查询由当前网络和系统解析配置处理。

第三方可以按其服务规则处理收到的请求；本次未核实各服务的日志保留期限、具体处理地域或再使用方式，不承诺其不记录 IP 或不保留数据。可查看Cloudflare 隐私政策了解该服务的说明，具体适用范围以服务方公布的内容为准。

Mac 另有外部浏览器 WebRTC / DNS 检查入口；点击后会在浏览器打开第三方网页，其实际检测和数据处理由该网站决定，本次未核实网页内部脚本。
这些请求用于测速和诊断，不代表该第三方与老野 WILDEN 存在合作、背书或数据处理协议。

05 / 本地保存与 Mac 功能

测速历史以本地文件保存，包含测试时间、节点名称、下载与上传速率、延迟、抖动、丢包估算、评分等结果，当前实现最多保留最近 1000 条测速记录，并提供清空操作。偏好与部分界面设置也保存在本机。

Mac 的 Bonjour 发现用于查看局域网内广播的服务，未见主动遍历整个子网的端口扫描。存储测速在你选择的目录写入生成的临时测试文件；若目录位于 NAS 或远程挂载，其存储设备也会收到对应读写请求。

Mac 首次使用的代理节点发现默认开启，可在设置中关闭。启用时，应用可读取已安装代理客户端的本地配置、节点名称和延迟记录，并通过其控制接口或本地套接字查询信息。切换节点会向该客户端发送控制请求，可能使用该客户端配置中的授权信息。未发现将这些配置上传到开发者服务器的路径；网络请求仍受代理客户端和所用节点的实际路由影响。

06 / 开发者是否收集数据

本次对当前源码与依赖配置的核查，未发现将测速历史、IP 或诊断结果上传到开发者自有服务器的代码路径，也未发现第三方广告、分析或自动崩溃上报 SDK。此结论不等于对最终App Store分发包的完整验证。

“未发现开发者服务器上传”不等于“没有第三方数据处理”。前述测速、IP 查询、诊断与 STUN 服务会直接接收请求；系统服务、代理服务及用户打开的外部网页也有各自的数据处理方式。

开发者魏强已确认：老野记事、老野网测均由本人以个人开发者身份独立开发和运营，没有公司或其他机构作为运营主体；没有额外使用客服平台、用户统计、广告、崩溃报告或其他服务收集、接收用户数据。

这项确认仅指开发者没有额外设置上述数据收集或接收服务，不表示应用完全不处理数据，也不取消前述第三方测速、IP查询、诊断及STUN等请求。第三方仍可能接收出口IP等网络信息，其日志保留期限和具体处理地域未核实。若你主动通过技术支持邮箱发送邮件，收件邮箱会收到你自行提供的联系信息与邮件内容；这与应用自动上传数据不同，请勿发送不必要的敏感信息。

当前源码配置与本说明的数据行为一致；最终App Store分发包、嵌入依赖及商店隐私申报仍需上架前核对，不能将本页直接视作完整的商店隐私申报。

07 / 你的选择与帮助

你可以避免启动吞吐测速、诊断和泄露检查，关闭可配置的代理节点发现，管理网络标识显示，并清空本地测速历史。退出应用可停止其主动功能；应用运行时的自动可达性检查和节点刷新不能被“未点击测速”完全排除。

清空应用历史不等于删除第三方服务器日志、系统日志或备份。支持材料中可能包含 IP、代理节点、路径等信息，请在自行提交前隐藏不必要的敏感内容。
